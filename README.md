# 任务管理看板（Task Kanban）

一个用 **Vue3 + Vite** 编写的纯前端任务管理看板，所有数据保存在浏览器 `localStorage`，刷新页面不丢失，无需任何后端服务。

## 功能特性

- **三列看板**：待办 / 进行中 / 已完成，实时统计每列任务数
- **新建任务卡片**：自定义标题、描述、分类标签，并指定初始所在列
- **拖拽切换状态**：卡片可在三列之间自由拖动（HTML5 原生 drag & drop）
- **分类筛选**：顶部标签胶囊按分类聚合筛选，支持「全部」
- **关键词搜索**：按标题或描述实时过滤
- **删除任务 / 清空已完成**：单卡删除 + 一键清理
- **本地持久化**：数据写入 `localStorage`（键名 `task-kanban-v1`）
- **完成度进度条**：顶部展示整体完成百分比与各状态数量
- **响应式布局**：桌面三列、窄屏自动堆叠为单列

## 技术栈

| 项 | 说明 |
| --- | --- |
| 框架 | Vue 3（Composition API，`<script setup>`） |
| 构建 | Vite 6 |
| 状态 | Vue `ref` / `computed`，无需额外状态库 |
| 存储 | 浏览器 `localStorage` |

## 本地运行

```bash
npm install
npm run dev
```

默认开发地址：`http://localhost:5199/`（可通过 `npm run dev -- --port 5173` 指定端口）。

生产构建：

```bash
npm run build
npm run preview
```

## 使用说明

1. 点击右上角「＋ 新建任务」填写标题、描述与分类标签；
2. 用鼠标按住卡片，拖到目标列即可改变任务状态；
3. 点击顶部标签胶囊按分类筛选，或使用搜索框过滤；
4. 卡片右上角「✕」删除任务；工具栏「清空已完成」批量清理；
5. 所有改动自动保存，刷新或下次打开页面数据仍在。
